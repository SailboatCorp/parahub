# Credit preference clarification

This update changes the ParaHub UI wording so "credit preference" is clearly about public outputs only.

Inside ParaHub, user display names still appear normally to authorised users. This is needed so the team can see who logged each reading, note, voice note, photo note, checklist action, or case entry.

The public credit preference is only for later use outside the software, such as reports, research notes, videos, presentations, publications, archives, or public case summaries.

Default public credit remains:

Anonymous investigator

This means a user can appear internally as Gene or John, while later public outputs can refer to them as Investigator, Investigator A, or the investigation team unless named credit is separately agreed.
